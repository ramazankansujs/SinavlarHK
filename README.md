## 💻 [Programlama Temelleri](https://github.com/ramazankansujs/SinavlarHK/tree/main/Programlama-Temelleri)

Bu bölüm, algoritma mantığından başlayarak C# programlama dilinin temel yapı taşlarını içerir.

* 🧠 [**Algoritma**](https://github.com/ramazankansujs/SinavlarHK/tree/main/Programlama-Temelleri/algoritma)
  * 🔀 [**akis-semasi**](https://github.com/ramazankansujs/SinavlarHK/tree/main/Programlama-Temelleri/algoritma/akis-semasi) - Akış şemaları (flowcharts) rehberi.
  * 📄 [**algoritma**](https://github.com/ramazankansujs/SinavlarHK/tree/main/Programlama-Temelleri/algoritma/algoritma) - Algoritma temelleri ve mantığı.
  * ⌨️ [**sozde-kod**](https://github.com/ramazankansujs/SinavlarHK/tree/main/Programlama-Temelleri/algoritma/sozde-kod) - Sözde kod (pseudocode) rehberi.

* 📦 [**Değişkenler**](https://github.com/ramazankansujs/SinavlarHK/tree/main/Programlama-Temelleri/De%C4%9Fi%C5%9Fkenler)
  * C# veri tipleri (int, string, double, bool vb.) ve ram/bellek yönetimi.

* 🔄 [**Döngüler (Donguler)**](https://github.com/ramazankansujs/SinavlarHK/tree/main/Programlama-Temelleri/Donguler)
  * `for`, `while`, `do-while` ve `foreach` döngü yapılarının kullanımları.

* 📚 [**Diziler**](https://github.com/ramazankansujs/SinavlarHK/tree/main/Programlama-Temelleri/Diziler)
  * Tek ve çok boyutlu diziler, indeks mantığı ve koleksiyon temelleri.

* 🎯 [**Olası Senaryolar**](https://github.com/ramazankansujs/SinavlarHK/tree/main/Programlama-Temelleri/Olasi-Senaryolar)
  * Sayı tahmin oyunu, vize/final notu hesaplama gibi örnekler.

## 🌐 [Web Tasarımı](https://github.com/ramazankansujs/SinavlarHK/tree/main/Web-Tasarimi)

Bu bölüm, modern bir web sitesi geliştirmek için gereken HTML iskeleti, CSS stilleri ve temel JavaScript etkileşimlerini içerir.

* 🏗️ **[Temel Web Sitesi Yapısı](https://github.com/ramazankansujs/SinavlarHK/tree/main/Web-Tasarimi/Temel-Web-Sitesi-Yapisi)**
  * HTML5 standartları, `head`, `body`, meta etiketleri ve sayfa iskeleti oluşturma.
* 📦 **[Divler ve Classlar](https://github.com/ramazankansujs/SinavlarHK/tree/main/Web-Tasarimi/Divler-ve-Classlar)**
  * HTML'de kutular oluşturma ve sayfada şekillendirme. 
* 📝 **[Metin Biçimlendirme](https://github.com/ramazankansujs/SinavlarHK/tree/main/Web-Tasarimi/Metin-Bicimlendirme)**
  * Başlıklar, paragraflar, kalın/eğik yazılar ve HTML anlamsal etiketleri.
* 📊 **[Tablo Oluşturma](https://github.com/ramazankansujs/SinavlarHK/tree/main/Web-Tasarimi/Tablo-Olusturma)**
  * `<table>`, `<tr>`, `<td>`, `<th>` kullanımları ile satır/sütun birleştirme (colspan/rowspan).
* 🎨 **[CSS](https://github.com/ramazankansujs/SinavlarHK/tree/main/Web-Tasarimi/CSS)**
  * Renkler, hizalamalar, Box Model (Kutu Modeli) ve Flexbox ile sayfa düzeni tasarımı.
* ⚡ **[JavaScript](https://github.com/ramazankansujs/SinavlarHK/tree/main/Web-Tasarimi/JavaScript)**
  * Buton etkileşimleri (onclick), form doğrulama ve dinamik stil değiştirme.
* 🫆 **[Tüm CSS Özellikleri](https://github.com/ramazankansujs/SinavlarHK/tree/main/Web-Tasarimi/Derslerdeki-Tum-CSS-Ozellikleri)**
  * Derslerde gördüğümüz bütün CSS özellikleri.
